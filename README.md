
# Web Development Lab

This repository contains practical assignments and exercises completed as part of the Web Development Lab from Week 1 to Week 14.

The lab covers the fundamentals of frontend and backend web development using HTML, CSS, JavaScript, PHP, and MySQL.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Weekly Practicals

### Week 1: HTML Basics
- Create a basic HTML document with paragraphs, headings, and lists.
- Add images, links, and tables to an HTML document.
- Create a simple form with various form controls (text inputs, radio buttons, checkboxes, etc.).

### Week 2: HTML5 and XHTML
- Create an HTML document using semantic HTML5 elements.
- Validate an XHTML document and correct any errors.
- Convert an HTML document to XHTML and ensure it follows proper syntax rules.

### Week 3: Introduction to CSS
- Create a basic CSS file and link it to an HTML document.
- Apply inline, internal, and external CSS styles to a webpage.
- Use CSS selectors to style different HTML elements.

### Week 4: CSS Styling and Box Model
- Style lists, links, and tables using CSS.
- Implement the box model: padding, margin, and border.

### Week 5: CSS Layout and Responsive Design
- Create a simple webpage layout using static, relative, absolute, and fixed positioning.
- Create a responsive webpage using media queries.

### Week 6: CSS Animations and JavaScript Basics
- Implement CSS animations and transitions on a webpage.
- Write a simple JavaScript program that uses variables, operators, and expressions.

### Week 7: JavaScript Functions and Control Structures
- Create JavaScript functions and demonstrate scope.
- Implement control structures (loops and conditionals) in JavaScript.

### Week 8: JavaScript Objects, Arrays, and DOM
- Create and manipulate JavaScript objects and arrays.
- Use the Document Object Model (DOM) to interact with an HTML document.

### Week 9: JavaScript Events and Error Handling
- Write a JavaScript program to handle events on a webpage.
- Write a JavaScript program that handles errors and debugging.

### Week 10: Introduction to PHP
- Write a basic PHP script to output "Hello, World!".
- Create a PHP script that uses variables, constants, and operators.
- Write PHP programs using control structures (conditionals and loops).

### Week 11: PHP Functions, Forms, and MySQL
- Create PHP functions and work with arrays.
- Develop a simple form in PHP and handle user input.
- Connect a PHP script to a MySQL database.

### Week 12: CRUD Operations and Sessions
- Perform CRUD (Create, Read, Update, Delete) operations in PHP.
- Implement session management in PHP.

### Week 13: Cookies and Error Handling in PHP
- Use cookies in PHP to store user preferences.
- Handle errors and debug a PHP application.

### Week 14: Full Stack Web Development
- Develop the frontend using HTML, CSS, and JavaScript.
- Create the backend using PHP and integrate it with a MySQL database.
